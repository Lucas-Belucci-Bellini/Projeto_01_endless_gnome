# Endless Gnome — Definition of Done

Uma tarefa só pode ser marcada como concluída quando todos os requisitos aplicáveis forem atendidos.

## Código

- [ ] Implementação atende ao requisito.
- [ ] Não há código morto criado desnecessariamente.
- [ ] Nomes são claros e seguem o padrão do projeto.
- [ ] Responsabilidades estão separadas.
- [ ] Referências para recursos/cenas existem.

## Gameplay

- [ ] Fluxo principal funciona.
- [ ] Casos normais funcionam.
- [ ] Casos de borda relevantes foram verificados.
- [ ] Não existe soft lock conhecido causado pela alteração.

## UI

- [ ] Estado apresentado corresponde ao estado real.
- [ ] Botões executam a ação esperada.
- [ ] Voltar/cancelar funciona quando aplicável.
- [ ] Textos estão legíveis.

## Testes

- [ ] Smoke test executado.
- [ ] Teste funcional executado.
- [ ] Regressão relevante verificada.
- [ ] Build/cena foi aberta em ambiente limpo quando aplicável.

## Documentação

- [ ] Documento relevante foi atualizado.
- [ ] Decisões importantes estão registradas.
- [ ] Instruções de uso estão claras.

## Git

- [ ] Branch tem nome correto.
- [ ] Commits seguem Conventional Commits.
- [ ] Não há arquivos temporários.
- [ ] Pull Request descreve alteração, testes e riscos.

## Revisão

- [ ] Outra pessoa consegue entender o que mudou.
- [ ] O impacto em outros sistemas foi considerado.
- [ ] Comentários/revisões foram resolvidos.
